# CS465 Full Stack Development I

## Architecture
### Compare and contrast the types of frontend development you used in your full stack project, including Express HTML, JavaScript, and the single-page application (SPA).
<p>
  In my full-stack project, I employed a combination of technologies to create a robust and efficient application. On the frontend, I utilized Express HTML for static content, JavaScript for dynamic interactions, and Angular for building complex SPAs. For the backend, I leveraged Node.js and Express.js to handle requests and manage server-side logic. To store and retrieve data, I chose MongoDB, a NoSQL database known for its flexibility and scalability. This technology stack allowed me to deliver a high-quality user experience while maintaining a scalable and maintainable backend architecture.
</p>

### Why did the backend use a NoSQL MongoDB database?
<p>
  MongoDB was a strategic choice for the backend of my full-stack project. Its schema-less design offered flexibility to adapt to evolving data structures, while its scalability ensured the application could handle increasing user loads. MongoDB's performance optimizations and document-oriented model aligned well with the project's requirements, and its native JSON support facilitated seamless integration with the JavaScript-based frontend. Additionally, MongoDB's capabilities for real-time updates were crucial for delivering a dynamic and responsive user experience.
</p>
