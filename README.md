# CS-465 Full Stack Development I

## Architecture
#### Compare and contrast the types of frontend development you used in your full stack project, including Express HTML, JavaScript, and the single-page application (SPA).
<p>
  In my full-stack project, I employed a combination of technologies to create a robust and efficient application. On the frontend, I utilized Express HTML for static content, JavaScript for dynamic interactions, and Angular for building complex SPAs. For the backend, I leveraged Node.js and Express.js to handle requests and manage server-side logic. To store and retrieve data, I chose MongoDB, a NoSQL database known for its flexibility and scalability. This technology stack allowed me to deliver a high-quality user experience while maintaining a scalable and maintainable backend architecture.
</p>

#### Why did the backend use a NoSQL MongoDB database?
<p>
  MongoDB was a strategic choice for the backend of my full-stack project. Its schema-less design offered flexibility to adapt to evolving data structures, while its scalability ensured the application could handle increasing user loads. MongoDB's performance optimizations and document-oriented model aligned well with the project's requirements, and its native JSON support facilitated seamless integration with the JavaScript-based frontend. Additionally, MongoDB's capabilities for real-time updates were crucial for delivering a dynamic and responsive user experience.
</p>

## Functionality
#### How is JSON different from Javascript and how does JSON tie together the frontend and backend development pieces?
<p>
  JSON (JavaScript Object Notation) and JavaScript are closely related, but they serve distinct purposes within web development. JSON is a lightweight, human-readable format for storing and exchanging data, while JavaScript is a programming language used to create dynamic and interactive web pages. JSON's key-value structure aligns well with JavaScript objects which makes it easy to parse and manipulate JSON data using JavaScript. This allows JSON to act as a bridge between the frontend and backend, facilitating data exchange and communication. The frontend sends JSON data to the backend as part of requests, and the backend can respond with JSON data, enabling seamless integration and data sharing between the two components of a web application.
</p>

#### Provide instances in the full stack process when you refactored code to improve functionality and efficiencies, and name the benefits that come from reusable user interface (UI) components.
<p>
  Throughout the development process, I consistently refactored code to enhance its readability, maintainability, and performance. By consolidating repetitive logic, optimizing database queries, implementing caching mechanisms, and structuring asynchronous operations effectively, I improved the application's overall efficiency and responsiveness. Additionally, the use of reusable UI components ensured a consistent look and feel, reduced development time, and simplified maintenance efforts. 
</p>

## Testing
#### Methods for request and retrieval necessitate various types of API testing of endpoints, in addition to the difficulties of testing with added layers of security. Explain your understanding of methods, endpoints, and security in a full stack application.
<p>
  API testing is a critical aspect of full stack development, ensuring that the application's endpoints function correctly and securely. By conducting various types of tests, including unit, integration, functional, performance, and security testing, developers can identify and address potential issues before the application is deployed. Security measures such as authentication, authorization, input validation, data encryption, and secure communication protocols are essential to protect sensitive data and prevent unauthorized access. However, these measures can introduce additional complexities into testing, requiring careful consideration and testing strategies to ensure the API's functionality and security under different conditions.
</p>
